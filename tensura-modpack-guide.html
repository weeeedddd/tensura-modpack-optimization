Installation

Schritt-für-Schritt — Step by step

1
CurseForge App installieren

Lade die CurseForge App von curseforge.com herunter und installiere sie auf deinem PC.

Install CurseForge App

Download the CurseForge App from curseforge.com and install it on your PC.

2
Tensura Abyss suchen & installieren

In der App: Minecraft → Suchfeld → „Tensura Abyss“ → Pack auswählen → Install klicken. Alle 348 Mods werden automatisch heruntergeladen.

Search & install Tensura Abyss

In the app: Minecraft → search field → “Tensura Abyss” → select pack → click Install. All 348 mods download automatically.

3
RAM auf 6–8 GB setzen

CurseForge App → Profil-Einstellungen → Java-Einstellungen → 6144 MB (Minimum) bis 8192 MB. Java 21 verwenden.

Set RAM to 6–8 GB

CurseForge App → Profile Settings → Java Settings → 6144 MB (minimum) up to 8192 MB. Use Java 21.

4
Pack starten

Pack über die CurseForge App starten. Der erste Start dauert 3–8 Minuten (Mods werden geladen). Danach lädt das Spiel schnell. Viel Spaß!

Launch the pack

Launch via the CurseForge App. The first launch takes 3–8 minutes (mods loading). After that the game loads quickly. Enjoy!

5
Maus-Fix (falls Sensitivity resettet)

Falls die Sensitivität nach Updates auf 0 springt: options.txt im Instanz-Ordner bearbeiten und die Datei danach schreibgeschützt setzen.

Mouse fix (if sensitivity resets)

If sensitivity jumps to 0 after updates: edit options.txt in the instance folder, then set the file to read-only.

# options.txt — Instanz-Ordner / Instance folder: .../Tensura Abyss/options.txt mouseSensitivity:0.5 # 0.5 = 100% | dann Datei Rechtsklick → Schreibgeschützt / then right-click → Read-Only rawMouseInput:true # Bypasses OS mouse acceleration — always enable this
✗
OptiFine NIEMALS installieren! — NEVER install OptiFine!
DE: OptiFine ist inkompatibel mit Embeddium und verursacht Sensitivity-Bugs + Rendering-Konflikte mit Tensura. Einzige Alternative: Embeddium + Oculus.
EN: OptiFine is incompatible with Embeddium and causes sensitivity bugs + rendering conflicts with Tensura. Only use: Embeddium + Oculus.

Performance & RAM

Einstellungen für stabiles Gameplay — Settings for stable gameplay

DE

Performance-Einstellungen

RAM: 6–8 GB optimal. Mehr als 8 GB verursacht längere GC-Pausen und verschlechtert die Performance.

Java: Immer Java 21 verwenden (bester Garbage Collector für Minecraft 1.21.1).

Shader: Complementary Unbound ist die beste Balance. Shadow-Resolution von 4096 → 2048 spart 30–50% FPS.

Grafik-Modus: Fancy für Shader, Fast für reine Performance. Simulations-Distanz auf 6–8 Chunks reduzieren bei Lag.

EN

Performance Settings

RAM: 6–8 GB optimal. More than 8 GB causes longer GC pauses and worsens performance.

Java: Always use Java 21 (best garbage collector for Minecraft 1.21.1).

Shaders: Complementary Unbound is the best balance. Reduce Shadow Resolution from 4096 → 2048 for 30–50% FPS savings.

Graphics mode: Fancy for shaders, Fast for pure performance. Reduce simulation distance to 6–8 chunks when lagging.

Super Diamond & Server-Tools

Neues Endgame-System & Server-Sicherheit — New endgame system & server safety

DE

Super Diamond Rework-System

Craften: 8× Diamant + 1× Netherstern (Wither-Kill) → 8× Super Diamond. Ein Netherstern-Gate stellt sicher, dass die Ressource erst im Endgame verfügbar ist.

Waffen-Rework: Netherit-Schwert/Axt + 2× Super Diamond + Netherstern → garantiert Sharpness V, Mending, Unbreaking III — Kombinationen, die sonst durchs Verzauberungs-Limit nicht erreichbar sind.

Rüstungs-Rework: Jedes Netherit-Teil + 2× Super Diamond → Protection IV + Unbreaking III + Mending.

Breath-System-Unlock: 4× Super Diamond + Totem der Unsterblichkeit → Breath Attunement Crystal. Rechtsklick verbraucht den Kristall und schaltet fortgeschrittene Fähigkeiten frei.

EN

Super Diamond Rework System

Crafting: 8× Diamond + 1× Nether Star (Wither kill) → 8× Super Diamond. A Nether Star gate ensures the resource is only available in the endgame.

Weapon rework: Netherite Sword/Axe + 2× Super Diamond + Nether Star → guarantees Sharpness V, Mending, Unbreaking III — combinations otherwise unreachable due to enchanting limits.

Armor rework: Any Netherite piece + 2× Super Diamond → Protection IV + Unbreaking III + Mending.

Breath system unlock: 4× Super Diamond + Totem of Undying → Breath Attunement Crystal. Right-click consumes the crystal and unlocks advanced abilities.

⚠
DE: Das Skill-Unlock (Breath-System) benötigt eine Anpassung an die exakte Tensura-Command-Syntax — siehe Kommentare in kubejs/server_scripts/balancing.js.
EN: The skill unlock (Breath system) needs adjustment to the exact Tensura command syntax — see comments in kubejs/server_scripts/balancing.js.
DE

RTP-Server-Sicherheit

Mod: SimpleRTP (natives NeoForge-1.21.1-Build, aktiv gepflegt).

Reichweite: Auf 6.000 Blocks begrenzt (statt Standard 10.000+) — verhindert Chunk-Generation-Spitzen und Server-Crashes.

Sicherheit: Eingebauter Scan verhindert Landung in Lava, Ozean, Void oder ohne Kopffreiheit.

Cooldown: 300 Sekunden zwischen zwei Teleports — verhindert RTP-Spam-Farming.

Config-Pfad: config/simplertp-common.toml — volle Anleitung in configs/simplertp_setup.txt.

EN

RTP Server Safety

Mod: SimpleRTP (native NeoForge 1.21.1 build, actively maintained).

Range: Capped at 6,000 blocks (instead of the default 10,000+) — prevents chunk-generation spikes and server crashes.

Safety: Built-in scan prevents landing in lava, ocean, void, or without headroom.

Cooldown: 300 seconds between teleports — prevents RTP-spam farming.

Config path: config/simplertp-common.toml — full guide in configs/simplertp_setup.txt.

DE

Worldgen & Portal

Vererbung: Die Dimension nutzt den Generator minecraft:noise mit dem Preset tectonic:overworld — sie erbt Tectonics riesige Schluchten & Klippen 1:1.

Biome: Der multi_noise-biome_source generiert dort ausschließlich die 3 Abyss-Biome — lückenlose Abdeckung, kein Worldgen-Crash.

Atmosphäre: Kein Himmelslicht, End-Sternenhimmel, fixierte Nacht — echtes Abyss-Feeling.

EN

Worldgen & Portal

Inheritance: The dimension uses the minecraft:noise generator with the tectonic:overworld preset — it inherits Tectonic’s huge canyons & cliffs 1:1.

Biomes: The multi_noise biome source generates only the 3 abyss biomes there — gapless coverage, no worldgen crash.

Atmosphere: No skylight, End starfield sky, fixed night — true abyss feeling.

Portal: craft a frame (Obsidian + Crying Obsidian + Dark Aether), place it and right-click with Dark Aether → travel to the abyss.

EN: Files live in kubejs/data/tensura_abyss/ (auto datapack). Setup + Tectonic fallback: configs/shadow_abyss_setup.txt. TerraBlender isn’t needed for the custom dimension (only for overworld injection — optional Java template included).
