Maus-Sensitivity-Bug — Permanenter Fix

Der Bug, bei dem die Maus-Sensitivität auf 0 zurückgesetzt wird, hat mehrere dokumentierte Ursachen. Tensura selbst verursacht diesen Bug nicht direkt — es sind begleitende Mods oder Systemeinstellungen.

Bekannte Verursacher

Mod / UrsacheProblemBelege
OptiFine Zufällige Sensitivity-Spikes, Kamera-Spins bei Chunk-Loads Dutzende GitHub-Issues (#394, #1528, #2602, #5287, #7080)
BetterFPS Alternative Sin/Cos-Algorithmus stört Maus-Berechnung Hypixel Forums, bestätigt
Controllable Virtual Mouse/Cursor interferiert auch ohne Controller GitHub-Issues #187, #261, #371, #525, #569
Modpack-Launcher CurseForge/Prism überschreiben options.txt bei Updates PrismLauncher Issue #1501
Windows Game Mode Stört Mouse-Smoothing auf Systemebene Minecraft Forum, breit dokumentiert

Fix-Anleitung

1

options.txt manuell setzen + sperren (zuverlässigster Fix)

# Pfad: C:\Users\dkage\curseforge\minecraft\Instances\Tensura Abyss\options.txt # Finde und setze: mouseSensitivity:0.5 # 0.5 = Standard (100%) rawMouseInput:true # Bypassed OS-Mausbeschleunigung # Dann: Rechtsklick → Eigenschaften → "Schreibgeschützt" → OK # Das verhindert, dass JEDE Mod den Wert überschreibt
2

Mod-Configs prüfen (im config/ Ordner)

# Falls Controllable installiert: controllable-client.toml → Virtual Mouse/Cursor DEAKTIVIEREN # Falls BetterFPS installiert: betterfps.cfg → Alternative Sin/Cos Algorithmus DEAKTIVIEREN # Falls Epic Fight installiert: epicfight-client.toml → Camera-Sensitivity prüfen # Tensura selbst: tensura-client.toml → Auf "sensitivity"/"mouse" Einträge prüfen
3

Windows-Einstellungen

# 1. Mauseinstellungen → Zeigeroptionen # → "Zeigerbeschleunigung" DEAKTIVIEREN # 2. Einstellungen → Spielen → Spielmodus → AUS # 3. Task-Manager → Beende Maus-Software: # Razer Synapse, Logitech G Hub, SteelSeries Engine # 4. Launcher: Rechtsklick → Kompatibilität # → "Hohe DPI-Skalierung überschreiben" # → Skalierung von: "Anwendung"
4

F8-Check: Drücke F8 ingame — Cinematic Camera könnte versehentlich aktiviert sein (fühlt sich an wie Sensitivity 0).

5

OptiFine ersetzen: Falls OptiFine installiert ist, ersetze es durch Embeddium + Oculus (Forge) oder Sodium + Iris (Fabric). OptiFine ist der häufigste Verursacher von Sensitivity-Bugs.

✓
Quick-Fix: Schritt 1 (Read-Only) + Schritt 5 (OptiFine ersetzen) lösen das Problem in >90% der Fälle dauerhaft.

RAM-Allocation

ⓘ
4–6 GB ist der Sweet Spot. Mehr als 8 GB verursacht längere GC-Pausen und verschlechtert die Performance. Nutze Java 21 für besseren Garbage Collector. Für 200+ Mods: 6–8 GB.
