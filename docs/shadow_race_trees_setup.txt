NACH DER INSTALLATION IM SPIEL VERIFIZIEREN (PFLICHT!)

 1. ASCENSION-TOML-SCHEMA: Die Key-Namen (spiritualHealth, isStartRace,
    previousRace, evolutionRequirementEP, hidden) sind eine konsistente
    VORLAGE. Starte das Pack einmal und vergleiche mit der von Ascension
    generierten Beispiel-Config in config/ — Keys ggf. umbenennen.
    Insbesondere "hidden" (versteckte Rasse) gegen die Doku pruefen.

 2. TENSURABRIDGE: setTensuraRace/getMagicules laufen ueber die Companion-
    Mod (dev/companion-mod). Ohne gebaute Companion-Jar greift der
    Scoreboard-Fallback (sg_magicule) — Gating funktioniert, aber der
    echte In-Mod-Rassenwechsel unterbleibt (Chat-Hinweis erscheint).

 3. BANDITEN-DORF: Standard ist minecraft:pillager_outpost. Wenn eine
    Struktur-Mod ein echtes Banditen-Dorf liefert (z.B. aus den vielen
    installierten Struktur-Packs), dessen Struktur-ID einfach in
    tags/worldgen/structure/bandit_villages.json ergaenzen —
    ID im Spiel per /locate structure herausfinden.

 4. LIEGE-POSE: Ohne playerAnimator wird die Ohnmacht via Blindness +
    Darkness + Slowness 255 inszeniert. Fuer eine echte Liege-Pose
    (Pose.SLEEPING) einen Packet-Hook in der Companion-Mod ergaenzen
    (Kommentar "TODO (Companion-Mod)" in secret_bandit_slayer.js).

 5. GILDEN-GUI: Die Geheimquest ist im Skript komplett spielbar
    (/shadowquest). Damit sie im Gilden-INTERFACE nur fuer den
    freigeschalteten Spieler erscheint: CommissionManager der Companion-
    Mod auf Scoreboard sg_secret_quest == 1 pruefen lassen
    (2 = abgeschlossen).
