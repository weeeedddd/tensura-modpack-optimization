# Cinematic Audit — Tensura Abyss

## Brand Motion Personality
Restrained, occult, monumental, precise, dangerous.

## Emotional Arc
- Opening (0–20%): awe at the sealed Abyss.
- Discovery (20–50%): curiosity through nine-stage evolution.
- Turning point (50%): the world is inhabited and materially valuable.
- Climax (50–85%): gear converts exploration into controlled power.
- Resolution (85–100%): I Am Atomic is earned, native, and legible.

## Audience and Device Context
Minecraft RPG players with medium-to-high technical familiarity. Mixed desktop/mobile audience; reference viewports are 1440×900 and 390×844. Performance target is mid-range hardware.

## Accessibility
WCAG AA contrast target, semantic HTML, visible keyboard focus, skip link, no baked text, and complete reduced-motion fallback.

## Visual System
Atmospheric Sublime with a restrained Symmetric Monument accent. Obsidian, violet, cyan energy, and silver interface metal match the mod UI.

## Color Temperature Progression
Cool void → neutral obsidian → cold violet biomes → pale silver safehouses → violet/cyan climax.

## Typography
System sans for readable copy and Georgia as a locally available editorial display face. No font requests.
