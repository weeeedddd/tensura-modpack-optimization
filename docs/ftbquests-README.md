# FTB Quests — Shadow Garden Chapter

A ready-to-use FTB Quests chapter for the **Eminence in Shadow** system
(pairs with `kubejs/server_scripts/shadow_garden.js`).

## Install

Copy the `config/` folder from here into your **instance root**, so the file
lands at:

```
<instance>/config/ftbquests/quests/chapters/shadow_garden.snbt
```

Then start the game (or run `/ftbquests reload` if already running). The
chapter **The Eminence in Shadow** appears in the quest book. FTB Quests
auto-discovers any `.snbt` in the `chapters/` folder — no index edit needed.

> Requires **FTB Quests** and **FTB Library** for NeoForge 1.21.1 in the pack.
> The quest tasks reference `kubejs:*` items, so the KubeJS scripts must be
> installed first (otherwise those tasks show as missing items).

## Quest tree (16 quests)

```
The Possessed → Slime Healing → Join the Shadow Garden ─┬─ Alpha   (combat)
                                                        ├─ Beta/Eta (info/research)
                                                        ├─ Gamma   (economy) → Mitsugoshi Town Hall
                                                        │                     → Marketplace & Guild
                                                        │                     → Activate Disguise
                                                        │                     → Defend vs. Cult → Slime Suit
                                                        └─ Delta   (beast)
                                Join ──→ Dark Aether ─┬─ I Am Atomic Ultimate
                                                      └─ Unlock Breath System
                    Slime Suit + I Am Atomic + Breath ──→ Ascend to Shadow Lord
```

## Editing

- Quest/task/reward IDs are unique 16-char hex (prefix `5A…`). If you paste
  this into an existing quest file, regenerate IDs to avoid collisions.
- The chapter is regenerated by `tools/gen_quests.py` in a previous build
  step; edit that script if you want to change the tree programmatically,
  or just edit quests live in the in-game FTB Quests editor.
- MineColonies task blocks use `minecolonies:blockhuttownhall` /
  `minecolonies:blockhutmarketplace` / `minecolonies:buildtool`. If your
  MineColonies version uses different registry names, adjust those tasks.
